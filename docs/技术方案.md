# xclaw - OpenClaw 桌面客户端技术方案

## 1. 项目概述

**项目名称**：xclaw  
**项目类型**：Electron 桌面应用  
**核心目标**：降低 OpenClaw 使用门槛，提供一键安装和可视化管理

---

## 2. 核心功能

### 2.1 一键安装
- 检测 Node.js（>=22.12.0），未安装则提示或自动安装
- 安装 pnpm（OpenClaw 要求）
- 安装 OpenClaw 依赖：`pnpm install`
- 构建 OpenClaw：`pnpm build`

### 2.2 自动配置
- 使用默认配置（国内用户习惯）
- 首次运行时引导配置模型 API Key（必须）
- Channel 配置（飞书/钉钉/企业微信/QQ）提供图文教程

### 2.3 启动管理
- 一键启动 OpenClaw Gateway
- 开机自启（通过 xclaw 自启实现）

### 2.4 更新管理
- 通过 Git Tags 检查更新
- 自动更新 OpenClaw 版本

---

## 3. OpenClaw 源码集成

### 3.1 源码位置
- 位于 `openclaw-src/` 目录
- 通过 Git 跟踪更新

### 3.2 安装命令
```bash
# 首次安装
pnpm install
pnpm ui:build
pnpm build

# 启动
pnpm openclaw gateway

# 更新后重建
pnpm install
pnpm ui:build
pnpm build
pnpm openclaw gateway restart
```

---

## 4. 技术架构

### 4.1 技术栈
- Electron 28+（桌面框架）
- React + TypeScript（前端）
- electron-builder（打包）

### 4.2 项目结构
```
xclaw/
├── openclaw-src/       # OpenClaw 源码
├── src/
│   ├── main/          # Electron 主进程
│   │   ├── index.ts   # 入口
│   │   ├── openclaw.ts # OpenClaw 管理
│   │   └── updater.ts  # 更新检查
│   ├── preload/        # 预加载
│   └── renderer/       # React 前端
├── resources/          # 静态资源
└── package.json
```
