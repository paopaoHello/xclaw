# xclaw - OpenClaw 桌面客户端技术方案

## 1. 项目概述

**项目名称**：xclaw  
**项目类型**：Electron 桌面应用  
**核心目标**：降低 OpenClaw 使用门槛，提供一键安装和可视化管理

---

## 2. 问题分析

### 2.1 当前痛点

| 痛点 | 影响用户 |
|------|----------|
| 需要安装 Node.js、配置环境变量 | 非技术用户 |
| 手动运行 `npm install` 等命令 | 命令行恐惧者 |
| 修改 JSON 配置文件容易出错 | 所有人 |
| 没有图形界面，不直观 | 普通用户 |
| 开机自启需要额外配置 | 大多数用户 |

### 2.2 解决方案

通过 Electron 桌面应用，一键完成所有配置。

## 4. 技术架构

### 4.1 技术栈

| 层级 | 技术选型 | 理由 |
|------|----------|------|
| 桌面框架 | Electron 28+ | 成熟稳定，生态丰富 |
| 前端框架 | React + TypeScript | 类型安全，开发效率高 |
| UI 组件 | Tailwind CSS + shadcn/ui | 现代化设计，快速开发 |
| 状态管理 | Zustand | 轻量级，简单易用 |
| 进程管理 | node-pty / child_process | 控制 OpenClaw 进程 |
| 打包工具 | electron-builder | 一键打包安装包 |

### 4.2 项目结构


### 4.3 核心模块设计

#### 4.3.1 OpenClaw 管理模块

```typescript
// src/main/openclaw.ts

interface OpenClawStatus {
  gateway: 'running' | 'stopped' | 'error';
  agent: 'running' | 'stopped' | 'error';
  version?: string;
}

class OpenClawManager {
  // 检查是否已安装
  async isInstalled(): Promise<boolean>;
  
  // 安装 OpenClaw
  async install(onProgress: (progress: number, message: string) => void): Promise<void>;
  
  // 获取状态
  async getStatus(): Promise<OpenClawStatus>;
  
  // 启动 Gateway
  async startGateway(): Promise<void>;
  
  // 停止 Gateway
  async stopGateway(): Promise<void>;
  
  // 启动 Agent
  async startAgent(): Promise<void>;
  
  // 停止 Agent
  async stopAgent(): Promise<void>;
  
  // 获取日志
  getLogs(type: 'gateway' | 'agent'): string[];
  
  // 检查更新
  async checkUpdate(): Promise<string | null>;
}
```

#### 4.3.2 IPC 通信

```typescript
// src/preload/index.ts

// 暴露给前端的 API

  },
});
```
