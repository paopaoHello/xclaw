# xclaw

基于 Electron 的 OpenClaw 桌面客户端 - 一键安装和管理 OpenClaw

## 🎯 项目目标

让 OpenClaw 变得更加易于使用，通过 Electron 桌面应用提供：

- ⚡ **一键安装** - 无需命令行经验，自动完成环境配置
- 🎛 **进程管理** - 可视化启动/停止/重启 OpenClaw 服务
- ⚙️ **配置管理** - 图形界面配置，无需手动编辑 JSON
- 🔄 **自动更新** - 及时获取最新版本

## 🛠 技术栈

- **Electron** - 桌面应用框架
- **React** - 前端界面
- **Node.js** - 后端逻辑
